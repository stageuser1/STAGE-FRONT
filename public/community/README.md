# 社群二维码资源

`components/growth/CommunityCard.tsx` 只引用一个静态文件：

```
public/community/wecom-group-qr.png
```

由业主放置，内容为**企业微信客户群「群活码」**（群满自动换群的那一种，不是固定群二维码——固定码在群满 200 人后会失效，而卡片是长期展示的）。

要求：

- 文件名与路径必须完全一致，卡片不做任何回退或探测。
- 正方形 PNG，建议 ≥ 528×528（卡片以 132 CSS 像素渲染，留足 4 倍图余量）。
- 四周保留二维码自身的静区，不要加边框或文字水印——卡片已经提供了标题与说明。
- 换群活码时直接覆盖同名文件即可，代码无需改动。

该文件未加入版本库时，卡片其余部分照常渲染，二维码位置显示 `alt` 文本。
