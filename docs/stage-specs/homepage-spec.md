## 一、设置页填写内容

### Company name and blurb

STAGE：面向中文用户的音乐留学申请信息平台。双产品结构——"院校与专业"（结构化的全球音乐学院申请与面试要求数据库，每条数据标注官方来源与核实日期）+ "IELTS Lab"（结构化雅思学习系统：弱点分析、复盘证据、提升追踪，不做 AI 评分）。目标用户：中国学生、家长、留学顾问。

### Any other notes

视觉基底为轻盈的浅色体系（参考现代轻盈 SaaS 落地页风格）：低饱和氛围底色、大量留白，每个区块严格遵循「小标签 → 大标题 → 副标题 → 内容」的统一骨架。字体策略为字体驱动设计（Apple 式）：极大字号跨度、紧凑字距、仅靠字重与字号建立层级、用色克制；中文标题使用苹方或思源黑体中黑/粗字重，大字号下收紧字间距。主色为蓝色系。页脚放置横贯全宽的超大号 STAGE 品牌字标作为整页收尾。摄影素材仅作小面积点缀（单色调处理的舞台题材，暗部为主、焦点唯一），不做整屏背景。

核心设计原则：诚实——所有界面元素只展示真实存在的功能。IELTS Lab 无评分、无 Band 预测、无 AI 考官，严禁出现任何分数类、评估类 UI。信任元素是品牌核心：来源标注、核实日期徽章（绿色对勾样式）需在数据界面中显性呈现。中文为主要语言，中英混排时保留院校名、学位名、专业术语的英文原文。移动端优先。

### 资产上传

- Logo（优先 SVG，其次高分辨率透明底 PNG）
- 已授权的中文字体文件（如有）
- 风格参考截图：已选定的两张落地页参考（其一作基底参考，其二仅参考其字体胆量与超大字标手法）
- **不挂旧代码仓库**（全站重构，避免被旧样式锚定）

## 二、页面结构（自上而下）

1. **导航栏**：STAGE 字标（左）｜院校与专业 · IELTS Lab · 指南 · 定价（右）｜「免费开始使用」实心按钮（最右）。联系我们移入页脚。
2. **首屏**：徽章 → 双句大标题 → 副标题 → 双 CTA → 信任行
3. **进行时双截图**：院校详情页主图 + 被唤起的 IELTS Lab 小卡（规格见第四部分）
4. **数据条**：120+ 全球音乐院校 ｜ 900+ 学位项目 ｜ 100% 招生要求均可追溯官方信息源 ｜ 15 覆盖国家与地区
5. **验证机制区块**（左文右图）：主题"每一所院校，均经过验证"，展示流程：来源抓取 → 结构化核对 → 标注核实日期；配图为院校列表页截图（展示广度：多校卡片 + 多维筛选器）
6. **IELTS Lab 区块**（右文左图）：反向定位文案 + 四模块（Reading / Listening / Writing / Speaking）；配图为听力复盘界面大图（原文高亮 + 时间戳 + 错因证据链接）
7. **用户场景区块**：三张卡——学生 / 家长 / 顾问（文案见第三部分）；可配单色调舞台题材小图
8. **转化区**：重复首屏双 CTA（主次不变）
9. **页脚**：指南细项、术语库、联系我们、备案信息等；底部为横贯全宽的超大 STAGE 字标

## 三、逐字文案定稿

### 首屏

- 徽章：`音乐申请 × IELTS 准备`
- 主标题：`找到适合你的学校` / `也准备好你的 IELTS`（两行）
- 副标题：`从院校筛选、项目要求，到有据可循的 IELTS 复盘训练，STAGE 帮音乐学生把复杂的申请准备，变成一条更清晰的路径。`
- 主按钮（实心）：`探索音乐院校 →`
- 次按钮（描边）：`体验 IELTS Lab`
- 信任行：`✓ 每一条招生要求，均可追溯至官方信息源。`

### 验证机制区块

- 小标签：`院校探索`
- 大标题：`每一所院校，均经过验证。`
- 流程三步：`来源抓取 → 结构化核对 → 标注核实日期`

### IELTS Lab 区块（反向定位）

- 小标签：`IELTS Lab`
- 定位文案方向（可微调措辞，立场不得改变）：我们不做 AI 考官，不做分数预测。我们做的是有据可循的复盘——每一道错题都能定位到原文证据，每一次练习都沉淀为你的弱点档案与提升轨迹。
- 四模块：Reading / Listening / Writing / Speaking

### 用户场景区块（三卡）

- 学生：`查清曲目要求，别练错方向`
- 家长：`看懂每一笔费用和每一个截止日期`
- 顾问：`可追溯的数据，敢直接发给客户`

## 五、禁止事项清单

1. 任何评分类 UI：预估分数、Band 预测、能力评估进度条、AI 考官形象
2. "模考"一词不得出现在任何文案中
3. 未经确认的功能不得出现在截图或文案中
4. 花哨渐变、重阴影、装饰性图形喧宾夺主
5. 逐字文案不得改写（第三部分标注"方向"者除外）
6. 命名统一为 "IELTS Lab"，不使用"雅思实验室"
