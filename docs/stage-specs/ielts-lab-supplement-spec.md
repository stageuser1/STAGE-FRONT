## 背景说明（可不投放给 Claude Design，供你自己参考）

分析的五家同行中，几乎全部以下列三件事作为核心卖点：AI 自动评分/Band 预测、录音+发音分析、广告位变现。这与 STAGE 的产品哲学是根本性的路线分歧。本文档只吸收与"打分/录音/广告"无关的信息架构与交互模式，并在采纳时统一改写为符合诚实原则的版本。

## 一、总览页更新（在已有"学习总览页"规格基础上增补）

### 新增：目标分数设定卡
- 位置：紧接在"核心指标行"（已练习题目/平均正确率/学习时长/连续学习）之后
- 内容：用户可为每个科目（Reading/Listening/Writing/Speaking）**自行输入**一个目标分数（如 `7.0`），此为用户个人意愿记录，**不是系统预测或计算得出的分数**
- 逐字标签：`我的目标分数`；每科一个可编辑数字输入框，范围 4.0–9.0，步进 0.5
- 说明小字（逐字）：`目标分数由你自己设定，仅用于个人规划参考。`
- 与首页呼应：此处设定的目标分数应与 STAGE 首页首屏小卡"目标：IELTS {分数}"的展示逻辑保持一致（若首页小卡功能已实现真实数据绑定，此处为该数据的编辑入口）

### 更新：四科模块卡内容加固（沿用已有卡片位置，仅升级卡片内部信息密度）
- 每卡结构：图标 + 科目名 + 副标题（如 `4 大类型` / `Task 1 & Task 2` / `五步流程`）+ 事实性要点列表（3–4条）+ 入口按钮
- 事实性要点示例（按科目自定，均为诚实的数据/能力描述，不含任何评分类表述）：
  - Reading：`题库总量 {N} 篇` `频次分层筛选` `讲解按答题解锁`
  - Listening：`题库总量 {N} 篇` `原文证据复盘` `套题模式可选`
  - Writing：`小作文按图型分类` `草稿自动保存` `范文按完成解锁`
  - Speaking：`九维度素材库` `个人故事构建` `可导出/导入`
- **严禁**在要点列表中出现"评分""估分""AI 反馈""发音分析"类表述

## 二、新增页面：题型说明参考

- 定位：独立的术语/参考页面，从总览页或题库筛选的"题型"维度旁提供入口链接（如题型筛选标签旁的 `?` 图标）
- 结构：左侧科目切换（Reading / Listening / Writing / Speaking），右侧为该科目下的题型列表
- 每个题型条目：题型名称（中英双语，如 `匹配题 Matching`）+ 一段大白话说明"这道题要求你做什么"+ 该题型在当前题库中的题量
- 逐字页面标题：`题型说明`
- 严禁在题型说明中混入任何该题型的具体真题内容或标准答案（保持纯粹的方法论说明，不越界成为"提前剧透"）

## 三、新手引导横幅（总览页顶部，可关闭）

- 复用院校列表页已确立的"个性化引导细条"视觉样式（细线条+小按钮，不做大横幅）
- 内容为三步说明，横向排列，逐字：
  1. `选科目` — 从 Reading、Listening、Writing、Speaking 中选择
  2. `去练习` — 在真实节奏下完成一次练习
  3. `复盘巩固` — 查看证据复盘，标记弱点，安排重测
- 首次进入 Lab 时默认展示，用户关闭后不再自动弹出（可在设置中重新开启）
- **第三步严禁写成"获取分数"或类似表述**——这是本次同行分析中最容易被带偏的一点，务必确认落地文案是"复盘巩固"而非任何分数导向的收尾

## 五、既有规则强化（本次同行分析中被反复验证的红线，重申不动摇）

以下规则并非新增，而是在查看五家同行方案后被反复确认为核心差异化，投放时应视为最高优先级检查项：

1. **严禁任何形式的自动评分/Band 预测**：包括分数圆环、四维度打分条、进度条式评估、"AI Band Score"类命名——本次分析的多家同行均以此为核心卖点，STAGE 明确不采纳
2. 同行 Speaking 方案中的三类功能（录音 / 发音分析 / 流利度评估）均属此类，一律不采纳
3. **严禁广告位**——已在三家同行截图中重复出现，确认为行业惯例但非 STAGE 选择
4. **严禁"答案/范文/讲解"在用户完成自己的尝试之前可见**——已横跨 Reading/Listening/Writing 三科确立，Speaking 同样适用
5. **严禁倒计时**，统一使用正计时
