## 全局规则（三个批次共用，每次投放都附上）

### 应用壳
- IELTS Lab 为独立应用壳：**左侧栏导航**，与官网营销页的顶部导航区分
- 左侧栏条目（逐字，自上而下）：`学习总览` `Reading` `Listening` `Writing` `Speaking` `复盘队列` `学习记录`
- 左侧栏顶部为 STAGE 字标 + `IELTS Lab` 标识，底部为返回官网入口
- 落地页次按钮「体验 IELTS Lab」与官网导航「IELTS Lab」链接到本应用的"学习总览"页

### 禁止事项（严格执行）
1. **严禁任何分数估算/Band 预测类 UI**：不得出现"估算""预估分数""Band"或任何将正确率折算为雅思分数刻度的展示。现有界面中的"当前阅读估算 2.0"卡片废除，替换方案见总览页规格
2. 严禁录音、麦克风、发音分析、AI 考官相关的任何 UI 元素或图标
3. 严禁营销横幅、弹窗、推广位插入学习界面（参考竞品的"点击揭秘""登录注册"横幅是反面案例）
4. 导航中不设"即将上线"类占位条目
5. 不做重度游戏化：无勋章、宝石、排行榜、吉祥物；仅保留"连续学习天数"一项
6. 命名统一为 "IELTS Lab"，不使用"雅思实验室"
7. 状态语言保持中性或正面：未开始的内容显示为可开始的入口，不用红色/警示色渲染落后状态

### 数据展示原则
- 所有指标使用原生数据：正确率、题量、覆盖度、时长、天数——永不投射为分数
- 每道题/每篇文章可显示"全体平均正确率"作为难度参照（借鉴成熟题库产品模式）
- 自动保存状态以低调的文字提示呈现（如"已自动保存"），不打断操作

# 批次一：应用壳 + 学习总览

## 学习总览页（Lab 着陆页）

自上而下：

1. **继续条**（有未完成练习时显示）：`继续上次：{文章标题}` + 进度 + 「继续」按钮；右侧灰字 `已自动保存`
2. **待重测提醒卡**（复盘队列有到期项时显示）：`有 {N} 道错题到了建议重测的时间` + 「去重测」按钮，链接到复盘队列
3. **核心指标行**（四卡并排，替代原"估算"卡）：`已练习题目` ｜ `平均正确率` ｜ `学习时长` ｜ `连续学习`
4. **四科模块卡**（四张并排）：每卡含科目名（Reading / Listening / Writing / Speaking）、题库总量、已练习进度（如 `已练习 2 / 223 篇`）、最近一次正确率、两个入口按钮 `浏览题库` `随机练习`。Speaking 卡的入口文案改为 `进入素材库` `继续构建`
5. **最近练习列表**（最多 5 条）：标题（英文 + 中文副题）· 科目 Part · 日期 · 我的正确率 · 「回顾」链接；右上角 `全部记录 →` 链接到学习记录页

# 批次二：题库列表 + 听力复盘 + 复盘队列 + 学习记录

## 题库列表页（Reading / Listening / Writing 共用模板）

1. **筛选区**（分面筛选，横向分组排列）：
   - 频次：`高频` `次高频` `非高频`（带各自篇数）
   - Part：P1 / P2 / P3（Listening 为 P1–P4）
   - 题型：按科目实际题型（如单选、多选、匹配、填空、判断）
   - 状态：`未练习` `已练习` `待重测`
   - 搜索框占位（逐字）：`搜索题目`
2. **题目列表**（行式布局）：每行含 标题（英文主 + 中文副）· Part 标签 · 题型标签 · 我的正确率（未练习则显示 `—`）· 全体平均正确率 · 状态点（已练/未练/待重测三色）· 行尾进入箭头
3. Writing 列表页额外规则：小作文（Task 1）按图型分组浏览：`数据图` `流程图` `地图` `示意图`，缩略图网格模式；大作文（Task 2）维持行式列表

## 听力证据复盘界面

- 双栏布局：**左栏原文 transcript，右栏题目与我的作答**
- 右栏每道错题带「查看证据」链接（cue link）；点击后左栏滚动至对应句并高亮，句旁显示时间戳 chip（如 `02:41`）
- 每道错题下方可标注错因标签（选自弱点模型的既有分类），标注后计入弱点档案
- 界面底部操作：`加入复盘队列`（主）｜`完成复盘`（次）
- Reading 复盘复用此模板（左栏为阅读原文，高亮定位句，无时间戳）

## 复盘队列页

- 队列列表，按建议重测时间排序，每行含：题目标题 · 科目 · 原练习日期 · 原正确率 · 已标注的错因标签 · `建议重测` 时间提示 · 「重测」按钮
- 重测完成后行内展示对比：`上次 {X}% → 本次 {Y}%`（Retest Measurement 的 UI 化）
- 空状态文案（逐字）：`队列是空的——去练习里犯点错，再回来消灭它们。`

## 学习记录页

- **时间线视图**：按日期分组的事件流（练习 / 复盘 / 重测三类事件，各自图标区分）
- **提升追踪图表**：正确率随时间的折线图，可按科目切换；Y 轴为正确率百分比，严禁换算为分数刻度
- 顶部汇总：总练习量、总时长、连续学习天数

# 批次三：Speaking 独立流程

Speaking 不采用"题目 → AI 答案"模式，界面沿五步流程组织，五步以横向步骤条常驻页顶：`题目 → 个人想法 → 答案构建 → 记忆巩固 → 独立表达`

1. **题目页**：题目卡（Part 1 / 2 / 3 分类浏览），选题后进入下一步
2. **个人想法页**：九维度引导卡（逐字，双语标签）：`WHAT 是什么` `WHO 谁` `WHEN 何时` `WHERE 何地` `WHY 为何` `MEMORY 记忆` `FEELING 感受` `CHANGE_OVER_TIME 变化` `COMPARISON 对比`；每个维度下是用户自己输入想法片段的输入区；已填维度打勾
3. **答案构建页**：左栏为用户的想法片段（按维度分组，可拖入右栏）；右栏为答案草稿区。**核心规则：右栏内容只能来源于左栏片段的组织与连接（traceability validation 的 UI 化）——界面不提供任何 AI 生成答案的按钮**
4. **记忆巩固页**：答案以关键词骨架呈现（连接词与用户核心词保留、其余淡化），支持逐级隐藏文字练习回忆
5. **独立表达页**：仅显示题目 + 极简关键词提示（可关闭），用户对照自查清单勾选完成情况（覆盖了哪些维度）；**无录音、无计分**，完成后记录一次"独立表达"事件到时间线
6. 全流程数据支持导出/导入（入口放在 Speaking 板块设置角落，低调呈现）
