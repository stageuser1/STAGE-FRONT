# STAGE 内容风格指南

面向用户的**内容呈现**规范:中文译名、措辞口径。

**与抽取规程分开的理由**:抽取逻辑管"这个事实是什么、有没有证据",内容呈现管
"用中文怎么说给读者听"。两者的判断依据不同 —— 前者看官网原文,后者看读者是谁。
混在一起会让"译得好听"侵蚀"译得准确"。抽取规程见
`docs/extraction/EXTRACTION_PROTOCOL.md`。

---

## §1 通用原则

### 1.1 不替官网下结论

译名与文案只做**转述**,不做**评价**。官网说"竞争性录取",就写竞争性录取;不写
"很难进""建议尽早准备"这类判断 —— 那是咨询意见,不是数据。

### 1.2 不带情绪色彩

面向所有学校复用的固定文案,尤其不能带判断色彩:同一句话会显示在"要求很严"和
"明确无要求"两种专业上,任何暗示难度的措辞都会在其中一种情形下失真。

### 1.3 不写死具体学校名

复用型文案里不出现某一所学校的名字。第一版为 Berklee 写的文案,下一所学校要能
原样使用。

### 1.4 译名以准确优先,不追求简短好听

专业名的译法要让读者能与官网英文对上号。宁可长一点,不要为了顺口而丢掉限定词。

## §3 固定文案

### 3.1 专业申报门槛区块

**标签**:专业申报门槛(入学后)

**说明文案(定稿 2026-08-10)**:

> 这所学校是"先考进学校、再选专业":上面是考进学校要满足的;下面是入学以后想读
> 这个专业还要满足的。

**两条约束(改动前必读)**:

1. **不写死校名** —— 这段文案要复用到其余所有学校。
2. **不带判断色彩** —— 它对"官网明确说无门槛"的专业同样会显示,所以不能写成
   "还要过的一关"那类让人觉得吓人的话。

**定稿过程**(留档,避免重复讨论):三个候选中,A 版("在这所学校,先被学校录取,
入学后才选定并申报具体专业……")准确但偏公文,读者要读两遍才反应过来是两件事;
C 版("考进这所学校,不等于就能读这个专业……还要过的一关")最口语,但带判断色彩,
违反约束 2。B 版用"上面/下面"的对比把两件事摆在一起,一眼可辨且中性,故取 B,
并按约束 1 把"伯克利"改为"这所学校"。

**渲染行为**:字段为 `null`(官网未说明)时**整块不渲染**。绝不显示"暂无要求" ——
那会让读者以为可以直接申报,而事实是我们不知道。

### 3.2 限额/竞争性专业的标记

限额或选拔性专业在 `major_declaration_requirements` 正文开头加 `⚠ ` 前缀,例如:

> ⚠ 限额专业,仅凭申请进入且录取具竞争性。

**不压缩成一句话概括** —— 这是对用户价值最高的信息,完整条件(资格前提、课程要求、
申请流程、录取依据)如实写入。
